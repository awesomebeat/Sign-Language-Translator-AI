# Система распознавания жестового языка с использованием искусственного интеллекта

Проект представляет собой прототип системы перевода жестового языка в текст, работающей в режиме реального времени с использованием технологий компьютерного зрения и искусственного интеллекта.

Система получает видеопоток с веб-камеры, распознаёт жесты пользователя с помощью нейросетевой модели, преобразует их в последовательность глоссов и формирует грамматически корректный текст на русском языке с использованием языковой модели.

Основная цель проекта - исследование возможностей применения современных методов компьютерного зрения и искусственного интеллекта для повышения доступности цифровых сервисов и упрощения коммуникации между людьми, использующими жестовый язык, и слышащими пользователями.

Ключевые возможности:

- распознавание жестов в режиме реального времени;
- работа без специализированного оборудования;
- обработка видеопотока с веб-камеры;
- запуск модели распознавания в формате ONNX;
- фильтрация нестабильных предсказаний;
- автоматическое формирование текста;
- история переводов и экспорт результатов;
- веб-интерфейс на базе Streamlit.

Технологический стек:
Python, OpenCV, NumPy, ONNX Runtime, Streamlit, Ollama, Qwen 2.5.
